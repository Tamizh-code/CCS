# Experiment 10: Intrusion Detection System
Compile: `javac SimpleIDS.java`
Run: `java SimpleIDS`
Enter sample log lines. Try `Failed login for user admin`, `Port scan detected`, and `Normal user session`. Type `EXIT` to stop.

This Java program is a small classroom IDS simulation. It is not a replacement for Snort and does not capture network packets.

For the Snort procedure described in the record, see `SNORT_GUIDE.md` in the package root.
